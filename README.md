# codechallenge

A JavaScript practice file (`main.js`) with six functions and some sample calls at the bottom of the file.

## Functions

- `findSum` — sum the numbers in an array
- `findFrequency` — return the most and least frequent items in an array of strings
- `isPalindrome` — test whether a string is a palindrome
- `largestPair` — largest product of adjacent integers
- `removeParenth` — remove a parenthetical segment from a string
- `scoreScrabble` — compute a Scrabble score for a word

## Getting started

```bash
node main.js
```

Practices: arrays, objects, strings, and basic algorithms.
